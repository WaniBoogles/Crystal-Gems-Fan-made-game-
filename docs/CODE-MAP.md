## 1. What the project is

A **fan-made 2D arcade action brawler** based on *Steven Universe*, written from scratch in
**vanilla HTML5 Canvas + CSS + Web Audio** — no engine, no framework, **no image assets in the
game code**. Every character, enemy, boss, platform and effect is drawn with Canvas 2D paths.

| Tier | File | How it runs |
| :--- | :--- | :--- |
| Source | `src/game.{html,css,js}` | Served over any static server (or `file://`) |
| Shipped game | `Crystal-Gems.html` (2.2 MB) | Single self-contained file: CSS, JS and 7 backgrounds inlined as base64 |
| Linux | `crystal-gems.sh` + `Crystal Gems!.desktop` | GTK3 + WebKit2 fullscreen window, browser kiosk fallback |
| Windows | `build/Crystal Gems.exe` | C# launcher embeds the HTML, serves it locally, opens Edge/Chrome `--app` |

### Runtime shape
* States: `title → playing ⇄ paused → victory | gameover`. Screens are DOM overlays
  (`.overlay-screen`); the canvas keeps rendering behind them.
* The loop is delta-time driven, so background-tab throttling doesn't warp timers.
* Camera tracks the midpoint of both players across a 2,600 px arena; the canvas is 1280×720.
* The whole stage (canvas + HUD + menus) lives in a fixed 1280×720 `#game-container` that is
  scaled to the window (`--gc-scale`), so layout is identical in the native shell and any browser.

## 4. Systems in plain terms

**Combat.** 3-hit chains per hero with per-move cadence/damage/knockback, a timed finisher
projectile, dodge i-frames, guard shield, and a Star Power meter that unlocks a 12-second
"Pink Overdrive" super state.

**Typing (new).** Each move slot carries one of 11 elements. `damageEnemy` computes
`dmg × typeMultiplier × STAB × vulnerability`, shows the verdict and applies that element's
rider (stun, slow, DoT, armour crack, charm…). Enemy typing lives in `ENEMY_TYPES`; projectiles
are tagged on the frame they spawn.

**Enemy AI.** Each type declares a role — brawler, jumper, flyer — plus a preferred standoff
range. Every attack has a telegraphed wind-up (scaled by the difficulty), and
`maxConcurrentAttackers` caps how many commit at once.

**Difficulty (new).** Five tiers drive 15 knobs read by `EnemyManager.reset`: HP/speed/cadence
multipliers, telegraph length, simultaneous attackers, evasion, elite chance, aggression, drop
rate, wave reinforcement count, boss HP, elite HP, knockback resistance and stage-clear healing.
Reinforcements are appended in `prepareWave`; bosses scale in `spawnEnemy`.

**Fusion.** Landing hits feeds `fusionEnergy`; at 100 % the pair fuses for a ~4 s invulnerable
screen-clearing blast, +1 heart and an 8 s "+25 % speed/damage" harmony buff (Malachite is denied
the heal — canon unstable fusion).

**Audio.** No audio files: 13 synthesised tracks (tempo + 32-note melodies) named after show
songs (*That Distant Shore*, *I Am Lapis Lazuli*, *Amethyst's Drum / Opal's Theme*) and 42 SFX.

## 5. Basis of the game

### 5.1 IP
*Steven Universe*, created by **Rebecca Sugar**, produced by **Cartoon Network** (2013–2019),
plus *The Movie* (2019) and *Future* (2019–2020). This is an **unlicensed fan project**.
The seven lobby landscapes are official key art (raw downloads preserved in
`assets/source-art/`, e.g. `thumb-1920-735772.png`), cropped to 1440×810.

### 5.2 Canon content
10 heroes with canonical weapons (Rose's shield, Garnet's gauntlets, Pearl's spear, Amethyst's
whips, Lapis' water wings, Bismuth's hammer, Jasper's crash helmet), 9 canonical fusions keyed by
gem pair, and an episode arc that follows the show's own progression: Beach City → Galaxy Warp →
Prime Kindergarten → the Cluster → Bismuth's Forge → Frozen North/Jasper → Pink Diamond's Zoo →
Homeworld → the Trial → *Change Your Mind* / Era 3.

Spellings were corrected in this revision where the original drifted from canon — Steven heals
with his **saliva** (not a Cookie Cat), and his shirt is coral-red, not pink.

### 5.3 Genre DNA
| Borrowed from | Where |
| :--- | :--- |
| Side-scrolling beat 'em up | 2,600 px arena, camera scroll, wave ranks, co-op |
| Plants vs. Zombies | `pvzWaveContainer` / `pvzWaveFill` and the "A HUGE WAVE IS APPROACHING" banner |
| Tekken / arcade fighters | Combo tracker overlay, Practice Dojo with infinite-HP dummy |
| Marvel vs. Capcom | 4 s invulnerable tag-fusion hyper |
| Left 4 Dead 2 | "LEFT 4 DEAD 2-STYLE LIVING LOBBY SLIDESHOW" (comment) behind the title screen |
| Pokémon | The whole type chart, STAB, and the (previously cosmetic) type badges |

## 7. Findings / open items

1. **⚠️ A GitHub personal access token is embedded in `.git/config`** in the `origin` URL.
   Rotate it and move to SSH or a credential helper.
2. **Fonts are still remote.** `src/game.html` links Fredoka One + Nunito from Google Fonts;
   offline the game falls back to system faces (no crash, slightly different menu typography).
   Bundling local font files would complete the offline story.
3. **DIAMOND is deliberately unfair** (2 hearts, no heal between episodes). If it proves
   impossible rather than hard, tune `stageHeal` / `waveSizeBonus` in `DIFFICULTY_CONFIG`.
4. **Character art is stylised chibi vector art**, not traced from official art. Garnet, Steven
   and Pearl were brought closer to canon this revision; Amethyst, Lapis, Peridot and Jasper were
   already close. `tools/character-sheet.html` is the review surface for further passes.
5. **Enemy bodies are abstract** (the `blade_quartz` is a tinted block). If enemy readability is
   the next priority, those ~25 draw methods in `EnemyManager` are the place to work.
6. **Practice Dojo** keeps infinite hearts and instant Overdrive by design — handy for testing
   type matchups.
7. **Native `<select>` widgets are untrustworthy.** WebKitGTK paints its own chrome over them, which
   is why the jukebox is now a custom dropdown (`enhanceSelect()` in `game.js`).
