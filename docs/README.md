# 🌟 Steven Universe: Crystal Gems! — Action Battler

> *"We are the Crystal Gems, we'll always save the day! And if you think we can't, we'll always find a way!"*

Welcome to **Crystal Gems!**, a handcrafted, feature-complete 2D arcade action battler inspired by *Steven Universe*, built using vanilla HTML5 Canvas, responsive CSS, and a real-time Web Audio API sound & music engine.

---

## 🎮 How to Play Immediately

### 🪟 Windows PC
* **Option 1 (Recommended)**: Double-click `Crystal Gems.exe` — a dedicated, standalone Windows application with hardware acceleration and full audio.
* **Option 2 (Fallback)**: Double-click `Play-Crystal-Gems.bat` or open `Crystal-Gems.html` directly in Chrome, Edge, Firefox, or Brave.

### 📱 Android Phone or Tablet
* Copy `Crystal-Gems.apk` to your Android device and tap to install.
* Optimized for 16:9 widescreen display with ergonomic dual-thumb virtual controls (virtual movement d-pad on left, attack diamond on right).
* 100% offline — no Wi-Fi or cellular connection needed.

### 🍎 iPhone, iPad, Mac & Linux
* Open `Crystal-Gems-Mobile.html` (for touch devices) or `Crystal-Gems.html` (for desktop) in any web browser (Safari, Chrome, Firefox).
* On Linux desktops, you can also launch `./crystal-gems.sh` or install `Crystal Gems!.desktop` for native kiosk play.

## 🕹️ Controls Guide

### 👤 1-Player Solo Mode
| Action | Keybinding |
| :--- | :--- |
| **Move Left / Right** | `A` / `D` |
| **Jump / Double Jump** | `W` or `Space` |
| **Crouch / Guard Shield** | `S` (Blocks incoming frontal attacks) |
| **Primary Attack Combo** | `J` (Multi-hit character-specific combo) |
| **Special Attack** | `K` (Projectile / heavy skill) |
| **Signature Skill** | `L` (Unique defensive or movement ability) |
| **Dodge Dash** | `I` (Invulnerable mobility phase) |
| **Pink Overdrive** | `U` or `O` (When Star Power Meter hits 100%) |
| **Pause / Settings** | `Escape` (Opens pause menu with volume controls) |

*Note: Gem Fusion is canonically reserved for 2-Player Co-Op mode (fusions require two synchronized partners).*

### 👥 2-Player Local Co-Op Mode
Play simultaneously on the same keyboard:

#### Player 1 (Left Side):
* **Move**: `A` / `D`
* **Jump**: `W`
* **Shield**: `S`
* **Attack**: `F`
* **Special**: `G`
* **Skill**: `H`
* **Dodge**: `E`
* **Overdrive**: `R`
* **Gem Fusion**: `V` (Triggers colossal screen nuke & Gem Harmony synergy buff!)

#### Player 2 (Right Side / Arrow Keys):
* **Move**: `Left Arrow` / `Right Arrow`
* **Jump**: `Up Arrow`
* **Shield**: `Down Arrow`
* **Attack**: `J`
* **Special**: `K`
* **Skill**: `L`
* **Dodge**: `I`
* **Overdrive**: `O`

### 📱 Mobile Touch Controls
* **Left Thumb**: Virtual D-Pad (◀ Left, ▶ Right, ▲ Jump).
* **Right Thumb**: Action Diamond:
  * 💥 **ATK**: Primary Combo
  * ✨ **SPC**: Special Attack
  * 🌟 **SKL**: Signature Skill
  * 💨 **DDG**: Dodge Dash
  * ⚡ **ODR**: Overdrive (glows when ready)
  * 💎 **FUSE**: Tag-Team Fusion (2-Player / Co-Op)

## 🛠️ Codebase Architecture & Developer Guide

The entire game is organized for maximum readability, zero external dependencies, and rapid customization:

* **`game.html`**:
  * Semantic layout: Game canvas (`1280x720`), HUD overlays, health bars, dialog boxes, and screens.
  * Modular modals for Character Selection (all 10 heroes), Settings & Audio, In-Game Pause, and Victory.

* **`game.css`**:
  * Steven Universe visual aesthetic with custom typography (`var(--su-font-display)`), star badges, and glowing borders.
  * True 16:9 widescreen aspect ratio locking with clean letterboxing on all displays.
  * Responsive scaling for desktop monitors, laptops, and mobile landscape phones.
  * High-performance mobile GPU rules (disabling heavy backdrop-filter blur on low-end devices and pausing hidden animations).

* **`game.js`**:
  * **`GemAudioEngine`**: Real-time algorithmic sound synthesis using `AudioContext`, oscillators, gain envelopes, and dual SFX/Music master gain nodes with independent volume sliders.
  * **`EnvironmentRenderer`**: Parallax scrolling system with drifting clouds, twinkling stars, landmark silhouettes, and cached sky gradients.
  * **`PlayerHero`**: Player controller, physics, jumping, shielding, attacking, dodging, health, and animations.
  * **`EnemyManager`**: Enemy spawning, AI behaviors, pathfinding, attack logic, and multi-wave queue management.
  * **`ParticleSystem`**: High-performance sparkles, rose petals, poof puffs, damage numbers, and impact sparks.
  * **`StevenUniverseGame`**: Master game state machine, input routing, collision detection, and screen transitions.

* **`scratch/bundle_mobile.py`**:
  * Python bundling script that inlines HTML, CSS, JavaScript, and base64 assets into single-file standalone web games (`Crystal-Gems.html`) and recompiles `Crystal-Gems.apk`.
